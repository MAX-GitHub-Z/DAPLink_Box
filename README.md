# 项目简介

目标是实现一个简易的调试工具，支持DAPLINK调试，以及其他功能
目前已实现功能
1、DAPLINK调试 支持使用keil进行DAP调试

2、支持STM32挂载fatfs

# 关键字

CMSIS-DAP TinyUSB STM32
